## Étape 1 : Télécharger IPTV Smarters Pro

### Sur Android (téléphones Samsung, Tecno, Infinix, etc.)

1. Ouvrez le **Google Play Store** sur votre téléphone
2. Tapez **"IPTV Smarters Pro"** dans la barre de recherche
3. Appuyez sur l'application développée par **Whmcs Smarters** (ou téléchargez-la via le [Play Store officiel](https://play.google.com/store/apps/details?id=com.nst.iptvsmarterstvbox))
4. Cliquez sur **"Installer"**
5. Attendez la fin du téléchargement (environ 30 secondes avec une bonne connexion 4G)

> ⚠️ **Attention** : Téléchargez uniquement depuis le Google Play Store officiel pour éviter les faux APK malveillants.

### Sur iPhone / iPad (iOS)

1. Ouvrez l'**App Store**
2. Recherchez **"IPTV Smarters Pro"**
3. Sélectionnez l'application et appuyez sur **"Obtenir"**
4. Authentifiez-vous avec votre Face ID, Touch ID ou mot de passe Apple
5. L'application se télécharge automatiquement

### Sur Smart TV (Samsung, LG, TCL)

- **Samsung (Tizen)** : Ouvrez le Samsung App Store, recherchez "Smart IPTV" ou "GSE Smart IPTV"
- **LG (WebOS)** : Ouvrez le LG Content Store, cherchez "GSE Smart IPTV"
- **Android TV / TCL** : Ouvrez le Play Store directement sur votre TV et installez IPTV Smarters Pro

Pour les TV qui ne supportent pas ces stores, une **clé Android TV** comme le Fire Stick ou un **Android Box** est recommandé.

## Étape 2 : Ouvrir l'Application et Choisir le Mode de Connexion

1. Lancez **IPTV Smarters Pro**

   - **"Connexion avec Xtream Codes API"** ← **La méthode recommandée pour iptvivoire.com**

   - "Importer le fichier de liste de lecture M3U"

**Choisissez : "Connexion avec Xtream Codes API"**

Après avoir choisi la méthode Xtream Codes, un formulaire apparaît. Remplissez-le avec les informations reçues par **WhatsApp** d'iptvivoire.com :

| Champ | Ce que vous devez saisir |
|---|---|

## Résolution des Problèmes de Buffering

Le buffering (l'image qui "gèle" ou les rondes qui tournent) est le problème le plus courant avec l'IPTV. Voici comment le résoudre :

### Cause 1 : Connexion internet trop lente

**Solution** :
- Vérifiez votre débit : ouvrez [fast.com](https://fast.com) dans votre navigateur
- Si < 10 Mbps, passez en qualité **SD** dans les paramètres de lecture
- Rapprochez-vous de votre box Wi-Fi ou utilisez un câble ethernet
- Éteignez et rallumez votre box internet

### Cause 2 : Serveur temporairement surchargé

**Solution** :
- Appuyez sur le bouton **"Suivant"** ou **"Changer de serveur"** dans le lecteur
- Certaines chaînes ont plusieurs flux disponibles — essayez-en un autre
- Contactez le **support WhatsApp d'iptvivoire.com** pour un changement de serveur

### Cause 3 : Cache de l'application plein

**Solution** :
1. Allez dans **Paramètres** de votre téléphone
2. Applications → IPTV Smarters Pro
3. **Vider le cache**
4. Relancez l'application

### Cause 4 : Problème DNS

**Solution** :
- Changez les DNS de votre téléphone : utilisez **8.8.8.8** (Google) ou **1.1.1.1** (Cloudflare)
- Sur Android : Paramètres → Réseau → DNS privé → Entrez "one.one.one.one"

### Cause 5 : Trop d'appareils connectés simultanément

**Solution** :
- Déconnectez les appareils qui ne regardent pas en ce moment
- Vérifiez le nombre de connexions simultanées autorisées par votre offre iptvivoire.com
