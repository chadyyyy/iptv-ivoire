## Installation de WESOPRO IPTV PRO selon votre appareil

### 📱 Sur Smartphone Android (Téléphone ou Tablette)

**Étape 1 — Télécharger l'application**

Ouvrez le **Google Play Store** sur votre téléphone. Dans la barre de recherche, tapez `WESOPRO IPTV PRO`. Sélectionnez l'application officielle dans les résultats et appuyez sur **Installer**.

**Étape 2 — Ouvrir l'application**

Une fois installée, ouvrez WESOPRO IPTV PRO. Lors du premier lancement, l'application vous demandera de choisir un mode de connexion.

**Étape 3 — Ajouter votre abonnement**

Appuyez sur **"Ajouter un compte"** puis sélectionnez **"Xtream Codes"**.

Remplissez les trois champs avec les informations que votre fournisseur vous a envoyées sur WhatsApp :
- **URL du serveur** : (exemple : `http://votre-serveur.com:8080`)
- **Nom d'utilisateur** : votre username unique
- **Mot de passe** : votre mot de passe unique

Appuyez sur **"Connexion"**. WESOPRO charge automatiquement toutes vos chaînes en direct, vos films et vos séries VOD. L'opération prend généralement 30 à 60 secondes selon votre connexion.

### 📺 Sur Smart TV (Samsung, LG, Hisense)

L'installation sur Smart TV est légèrement différente selon la marque, mais le principe reste identique.

**Étape 1 — Accéder au Store de votre TV**
- **Samsung** : Ouvrez le **Samsung Apps Store** depuis le menu principal
- **LG** : Ouvrez le **LG Content Store**
- **Hisense** : Ouvrez le **Vidaa App Store**

**Étape 2 — Chercher WESOPRO**

Dans la barre de recherche du store, tapez `WESOPRO` et installez l'application.

> **Si WESOPRO n'apparaît pas dans le store de votre TV :** Votre Smart TV utilise probablement Android TV. Dans ce cas, activez les "Sources inconnues" dans les paramètres, puis installez le fichier APK depuis le navigateur de votre TV.

**Étape 3 — Configuration avec la télécommande**

La navigation avec la télécommande est simple. Utilisez les touches directionnelles pour naviguer et le bouton **OK** pour valider. La saisie du texte (URL, username, password) se fait via le clavier à l'écran.

**Conseil pratique :** Connectez un clavier Bluetooth à votre Smart TV pour saisir vos identifiants beaucoup plus rapidement.

### 📦 Sur Android TV Box (Box Android)

Les boxes Android (MXQ, X96, H96, etc.) sont les appareils les plus utilisés en Côte d'Ivoire pour l'IPTV.

**Étape 1 — Installation via Google Play Store**

Si votre box est connectée à un compte Google, ouvrez le Play Store et installez WESOPRO IPTV PRO normalement.

**Étape 2 — Installation via fichier APK (si pas de Play Store)**

Certaines boxes Android basiques n'ont pas le Play Store. Dans ce cas :
1. Ouvrez le navigateur de votre box et cherchez `WESOPRO IPTV PRO APK`
2. Téléchargez le fichier APK depuis un site officiel
3. Dans les **Paramètres > Sécurité**, activez **"Sources inconnues"**
4. Ouvrez le gestionnaire de fichiers, trouvez le fichier APK téléchargé et installez-le

**Étape 3 — Configuration identique**

La configuration est exactement la même que sur smartphone Android : Ajouter un compte → Xtream Codes → URL + Username + Password.

## Configurer le Guide des Programmes (EPG) sur WESOPRO

L'EPG (Electronic Program Guide) est le guide des programmes qui vous indique ce qui passe actuellement sur chaque chaîne, et ce qui va suivre.

**Comment activer l'EPG :**
1. Allez dans **Paramètres** de WESOPRO
2. Sélectionnez **"Guide EPG"**
3. Saisissez l'**URL EPG** communiquée par votre fournisseur
4. Appuyez sur **"Mettre à jour"**

Chez **IPTV Ivoire**, l'URL EPG est fournie automatiquement avec vos identifiants Xtream Codes — vous n'avez rien à configurer manuellement.

## Problèmes courants et solutions

### ❌ L'application affiche "Authentification échouée"
**Cause :** Vos identifiants sont incorrects ou votre abonnement a expiré.
**Solution :** Vérifiez que vous avez copié l'URL exactement telle qu'elle vous a été envoyée (sans espace, sans faute de frappe). Contactez votre fournisseur sur WhatsApp pour confirmer que votre abonnement est actif.

### ❌ Les chaînes bufferisent (coupures fréquentes)
**Cause :** Votre connexion internet est trop faible pour le flux HD ou 4K.
**Solution :** Passez en qualité SD dans les paramètres de lecture. Si le problème persiste même en SD, essayez de vous rapprocher de votre box WiFi ou de passer en connexion filaire (câble ethernet).

### ❌ Certaines chaînes affichent "Stream indisponible"
**Cause :** Certains canaux peuvent être temporairement hors ligne (maintenance serveur).
**Solution :** Attendez quelques minutes et relancez la chaîne. Un bon fournisseur comme IPTV Ivoire dispose d'une technologie Anti-Freeze Stream-Stable™ avec des canaux de secours automatiques.

### ❌ L'application plante au lancement
**Solution :** Désinstallez et réinstallez l'application. Effacez aussi les données de cache dans **Paramètres > Applications > WESOPRO > Vider le cache**.
