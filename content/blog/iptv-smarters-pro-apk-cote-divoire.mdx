## Qu'est-ce qu'un APK ?

Un **APK** (Android Package Kit) est le format de fichier d'installation des applications Android. Normalement, les applications s'installent via le **Google Play Store**. Mais dans certains cas (TV Box, Fire Stick, versions non disponibles dans votre pays), vous pouvez installer une application directement via son fichier APK.

> ⚠️ **Important** : Téléchargez toujours les APK depuis des sources officielles et de confiance pour éviter les logiciels malveillants.

## Option 1 : Télécharger IPTV Smarters Pro via le Google Play Store (recommandé)

**La méthode la plus sûre** pour les téléphones Android standard :

1. Ouvrez le **Google Play Store** sur votre téléphone

## Option 2 : Installer l'APK sur Fire Stick ou Android Box

Pour les appareils qui n'ont pas accès au Google Play Store (Amazon Fire Stick, certaines Android Box), voici comment installer l'APK IPTV Smarters Pro :

### Étape 1 : Autoriser les sources inconnues

Sur **Amazon Fire Stick** :
1. Paramètres → Mon Fire TV → Options développeur
2. Activez **"Applications de sources inconnues"**

Sur **Android Box** :
1. Paramètres → Sécurité
2. Activez **"Sources inconnues"** ou **"Installer des apps inconnues"**

### Étape 2 : Télécharger l'APK

Sur votre **Fire Stick** ou **Android Box** :
1. Installez l'application **"Downloader"** depuis le store Amazon ou le Play Store
2. Ouvrez Downloader et entrez l'URL du site officiel de IPTV Smarters (smarters.com)
3. Téléchargez la version APK pour Android TV
4. Confirmez l'installation quand demandé

### Étape 3 : Installer l'APK

1. Naviguez jusqu'au fichier APK téléchargé
2. Appuyez sur **"Installer"**
3. Attendez la fin de l'installation
4. Ouvrez l'application
