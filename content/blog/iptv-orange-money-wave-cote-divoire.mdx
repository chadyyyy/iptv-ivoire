## Méthode 1 : Paiement par Orange Money

**Orange Money** est le moyen de paiement mobile le plus répandu en Côte d'Ivoire. Voici comment l'utiliser pour votre abonnement IPTV :

### Option A : Via le Code USSD (sans internet)

1. **Composez le `#144#`** sur votre téléphone Orange
2. Dans le menu, sélectionnez **"Payer une facture / Paiement marchand"**
3. Entrez le **numéro marchand** d'iptvivoire.com (disponible sur le site ou par WhatsApp)
4. Entrez le **montant** correspondant à votre offre (2 500, 6 000 ou 18 000 FCFA)
5. Entrez votre **code PIN Orange Money** à 4 chiffres
6. Confirmez la transaction
7. Vous recevez un **SMS de confirmation** avec le numéro de transaction

### Option B : Via l'Application Orange Money

1. Ouvrez l'application **Orange Money** sur votre téléphone
2. Appuyez sur **"Envoyer"** ou **"Payer un marchand"**
3. Entrez le **numéro de téléphone** d'iptvivoire.com
4. Saisissez le montant de votre offre
5. Vérifiez les informations et confirmez avec votre **PIN**
6. Prenez une **capture d'écran** du reçu

> ✅ **Conseil** : Assurez-vous d'avoir le solde suffisant sur votre compte Orange Money avant de commencer. Vous pouvez recharger votre compte dans n'importe quelle boutique Orange ou chez un distributeur agréé.

## Méthode 2 : Paiement par Wave

**Wave** est devenu en quelques années l'une des applications de paiement les plus populaires en Côte d'Ivoire, notamment pour ses frais réduits.

### Étapes de paiement Wave

1. Ouvrez l'application **Wave** sur votre smartphone
2. Sur l'écran principal, appuyez sur **"Envoyer"** (flèche vers la droite)
3. Entrez le **numéro de téléphone Wave** d'iptvivoire.com
4. Saisissez le **montant exact** de votre offre
5. Ajoutez une **note** si souhaité (ex: "Abonnement IPTV 3 mois")
6. Confirmez avec votre **code PIN Wave** ou votre **empreinte digitale**
7. La transaction est confirmée immédiatement

### Avantages du paiement Wave

- ✅ **Frais réduits** par rapport aux autres méthodes
- ✅ **Confirmation instantanée**
- ✅ **Pas de frais pour les envois entre particuliers**
- ✅ **Interface simple et rapide**

> ⚠️ **Important** : Vérifiez que le numéro destinataire appartient bien à **iptvivoire.com** avant de confirmer.

## Méthode 3 : Paiement par MTN Mobile Money (MoMo)

Si vous êtes client **MTN Côte d'Ivoire**, vous pouvez également payer avec **MTN Mobile Money** :

### Étapes de paiement MTN MoMo

1. Composez le **`*133#`** sur votre téléphone MTN ou ouvrez l'application **MTN MoMo**
2. Sélectionnez **"Paiements"** puis **"Paiement marchand"**
3. Entrez le **numéro marchand** d'iptvivoire.com
4. Saisissez le **montant** de votre offre
5. Entrez votre **code PIN MTN MoMo**
6. Confirmez la transaction
7. Gardez le **SMS de confirmation**

> **Astuce** : MTN MoMo fonctionne parfaitement même dans les zones avec une couverture réseau limitée, tant que vous avez du crédit téléphonique.

- Le **numéro destinataire**

Entrez vos identifiants dans **IPTV Smarters Pro** (ou l'application de votre choix) et commencez à regarder. C'est aussi simple que ça !

## Que Faire en Cas de Problème de Paiement ?

1. Attendez **5 minutes** — le SMS de confirmation peut parfois être retardé
2. Vérifiez votre **historique de transactions** dans l'application (Orange Money, Wave ou MTN MoMo)
3. Si le montant a bien été débité, contactez le support **WhatsApp d'iptvivoire.com** avec une copie de votre historique

### J'ai envoyé un mauvais montant

Contactez immédiatement le support **WhatsApp** d'iptvivoire.com avec :
- La preuve de votre paiement
- Le montant correct que vous souhaitiez payer
- L'offre désirée

L'équipe régularisera la situation rapidement.

### Mon compte Orange Money / Wave est insuffisant

Rechargez votre compte :
- **Orange Money** : Dans une boutique Orange ou chez un distributeur avec `#144#`
- **Wave** : Via dépôt dans un point Wave ou par virement depuis un autre compte
- **MTN MoMo** : Dans une boutique MTN ou chez un agent MoMo
